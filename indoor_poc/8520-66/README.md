# ซิมโดรน ESP32-C3 บอร์ดเดียว

เริ่มจาก [mission/mission.cpp](mission/mission.cpp) สำหรับภารกิจขึ้นบิน หยุด อ้อมกล่อง และถึงเส้นชัย ตัวควบคุมส่งคำสั่งให้มอเตอร์ brushed สี่ช่องในซิมที่รอบ 4 ms ส่วน [สเก็ตช์บนโต๊ะ](c3_timing_bench/c3_timing_bench.ino) ใช้วัดเวลาการอ่าน IMU ผ่าน USB ยังไม่มีเฟิร์มแวร์บินจริงที่ผ่านการทดสอบ

## ชุดต้นแบบ

- ESP32-C3 Super Mini, มอเตอร์ 8520 × 4, ใบ 66 มม. × 4, แบต 1S 300 mAh หนึ่งก้อนบนลำ และวงจรขับ brushed 4 ช่อง
- เซนเซอร์ 5 ตัวคือ MPU6050 (IMU), VL53L0X (ระยะหน้า), BMP280 (ความดัน), SHT31 (อุณหภูมิและความชื้น) และ KY-018 (แสงผ่าน ADC)
- SG90, LED, buzzer, โครงและสายรวมอยู่ในประมาณการน้ำหนัก กรณีหลักกำหนดน้ำหนักรวม 62 กรัม

## รันภารกิจซ้ำ

ใช้คอมไพเลอร์ C++17 สำหรับซิม ส่วน Python, Pillow และ Matplotlib ใช้สร้างภาพ คำสั่งด้านล่างเริ่มจาก root ของ repo และเขียนผลใหม่ในไดเรกทอรีชั่วคราว

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
mission_dir="$PWD/indoor_poc/8520-66/mission"
run_dir=$(mktemp -d)
c++ -std=c++17 -O3 "$mission_dir/mission.cpp" -o "$run_dir/mission"
cd "$run_dir"
./mission > development.csv
./mission validate > validation.csv
./mission light > ky018.csv
cp "$mission_dir/render.py" .
python render.py
```

`validate` สร้างเส้นทาง seed 302 ให้สคริปต์สร้างกราฟและ GIF ส่วน `light` สร้างชุดทดลอง KY-018 แยกออกมา ใน CSV ของชุดแสง mode 0 คือซิมเดิม, 1 คืองาน ADC แบบรอ, 2 คือแบ่งเวลาอ่านหลังงานคุมบิน, 3 คือแบบแบ่งเวลาพร้อมเพิ่มระยะขยับข้างเป็น 56 ซม. บุคคลที่ใช้ไลบรารีสุ่ม C++ คนละ implementation อาจได้ผลราย seed ต่างกัน

## งานถัดไป

1. วัดน้ำหนักพร้อมบินและแรงยกของมอเตอร์สี่ตัวพร้อมกันจากแบตก้อนเดียว ที่ 18 กรัมแรงต่อมอเตอร์ เมื่อแรงยกตก 18% ซิมเหลือแรงยกรวม 59.04 กรัมแรงสำหรับลำ 62 กรัม
2. ใช้สเก็ตช์ทดสอบเวลาบน C3 กับ MPU6050 แล้วเพิ่มงานอ่านเซนเซอร์จากชุดจริงเพื่อวัดรอบที่พลาด สเก็ตช์ปัจจุบันวัดเวลา IMU และสแกนที่อยู่ I²C ยังไม่ได้อ่าน KY-018
3. ตรวจการประมาณความเร็วด้านข้าง ซิมมีค่าความเร็วพร้อมสัญญาณรบกวนให้ตัวควบคุม ฮาร์ดแวร์ยังต้องพิสูจน์ว่าวัดระยะขยับข้างได้พอ อัตราแรงยกตกและเวลางาน ADC เป็นสมมติฐานสำหรับทดสอบความไว
