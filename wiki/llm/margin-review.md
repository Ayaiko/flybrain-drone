# เลือกระยะเผื่อเบรกบนสนาม hard 0

ใช้ fastsim รุ่น b7eb08b เพื่อเทียบเที่ยวบินเดิมได้ สนามเดียวกัน จุดเริ่มเดียวกัน สัญญาณรบกวนเดียวกัน เพดาน 600 วินาที ระยะเบรกคิดจากค่าฐาน (เมตร) บวกเวลาชดเชย (วินาที) คูณความเร็วที่วัดได้ (เมตร/วินาที) ทั้งสี่รุ่นใช้กล้องและ ToF ชุดเดิม

| รุ่น | ค่าฐาน (ม.) | เวลาชดเชย (วินาที) |
|---|---:|---:|
| baseline | 0.45 | 1.00 |
| fixed | 0.70 | 1.00 |
| balanced | 0.55 | 1.25 |
| moderate | 0.60 | 1.00 |

## จุดเริ่ม 0

คำสั่งเดินหน้าแยกจากกันครั้งแรกตอน 30.87 วินาที ที่ y = 9.02 ม. ToF อ่าน 0.572 ม. baseline สั่งเดินหน้า 0.8 ม./วินาทีและชนต้น c0 ที่เวลา 32.07 วินาที ส่วน fixed สั่งหยุดแล้วสแกน หลบต้นแรกได้ แต่เข้าสู่เส้นทางที่ชน 6 ครั้งในช่วง 122.30–171.40 วินาที ตำแหน่งตามแนวสนามอยู่ที่ 13.59–15.13 ม. เป็นวัตถุ 5 ชิ้น มีต้น c38 ที่ชนซ้ำอีกครั้ง ค่า ToF ขณะชนทั้งหกครั้งเรียงตามเวลาคือ 4.00, 4.00, 4.00, 3.35, 1.65, 1.81 เมตร การเปลี่ยนระยะเบรกเปลี่ยนเส้นทางที่ลำเลือกด้วย เซนเซอร์หน้าหนึ่งค่าไม่ระบุตำแหน่งที่ขอบลำสัมผัสได้

## ผลรายจุดเริ่ม

แต่ละช่องแสดงจำนวนครั้งที่ชน / ระยะคืบหน้าสูงสุด (เมตร) จุดเริ่ม hard 0/0 และ 0/1 ใช้เทียบตัวทดลอง จุดเริ่ม 2, 3 และ medium 2/1 ใช้ทวนสอบ

| สนาม / จุดเริ่ม | baseline | fixed | balanced | moderate |
|---|---:|---:|---:|---:|
| ff_easy_0 / 0 | 0 / 80.0 | 0 / 80.0 | 0 / 80.0 | 1 / 80.0 |
| ff_hard_0 / 0 | 1 / 48.0 | 6 / 44.4 | 0 / 44.4 | 1 / 47.8 |
| ff_hard_0 / 1 | 9 / 48.0 | 1 / 47.6 | 1 / 47.8 | 0 / 47.8 |
| ff_hard_0 / 2 | 3 / 48.0 | 2 / 47.6 | 1 / 44.2 | 1 / 47.7 |
| ff_hard_0 / 3 | 5 / 47.4 | 1 / 42.0 | 2 / 48.6 | 2 / 47.9 |
| ff_medium_2 / 1 | 3 / 52.5 | 0 / 52.5 | 2 / 52.6 | 1 / 52.5 |

เลือก moderate เป็นรุ่นทดลองชื่อ scan-front-060 สำหรับสนาม hard 0 รวม 4 จุดเริ่ม ชน 4 ครั้ง ระยะเฉลี่ย 47.8 เมตร เทียบ baseline ชน 18 ครั้ง ระยะเฉลี่ย 47.85 เมตร และ fixed ชน 10 ครั้ง ระยะเฉลี่ย 45.4 เมตร ทั้งสี่จุดเริ่มของ moderate ยังติดก่อนเส้นชัย ส่วน easy 0 จุดเริ่ม 0 รุ่น moderate ถึงทางออกแต่ชน 1 ครั้ง ขณะที่ baseline, fixed และ balanced ถึงโดยไม่ชน จึงคงค่าเริ่มต้นเดิมไว้

## ไฟล์และการสร้างซ้ำ

[กราฟ](margin-review.png) · [ผลตัวเลข](margin-review.json) · [ผลทดสอบเวลาตำแหน่ง](margin-pose-clock.json) · [วิดีโอ 3D ขาวดำ](../../results/videos/margin-review-3d.mp4)

ใช้ตัวจำลอง b7eb08b พร้อมไฟล์ viz/margin_review.py และไฟล์สนามเดียวกัน รัน `.venv/bin/python viz/margin_review.py /tmp/margin-traces --world ff_hard_0 --rep 0` ซ้ำสำหรับ rep 1, 2, 3 และ ff_medium_2 rep 1, ff_easy_0 rep 0 จากนั้นรัน `.venv/bin/python viz/margin_review.py /tmp/margin-traces --choice moderate` เพื่อสร้างกราฟและคลิป วิดีโอเปรียบเทียบ fixed กับตัวเลือกที่ระบุ ใช้พิกัดจาก trace และรูปทรงจริงจากสนามจำลอง แสดงสามช่วงเวลาที่ 1x จุดเริ่ม 1 ใช้ baseline เป็นฝั่งก่อนแก้

ระหว่างการรัน NumPy แจ้งคำเตือนในการคูณเมทริกซ์ ผลนี้มาจากตัวจำลองและยังไม่ได้ทดสอบกับโดรนจริง

ลองเปลี่ยนเฉพาะช่วงเวลาที่ใช้หารการกระจัดและมุมหมุนเป็นเวลาระหว่างตัวอย่างตำแหน่ง 50 Hz ที่นำมาใช้จริงในซิม โดยคงอัตราการทำงานของวงจรมองเห็นไว้ที่ 30 Hz รัน scan-front เป็นเวลาไม่เกิน 180 วินาที จุดเริ่ม 1 ดีขึ้นจาก 1.3 เป็น 2.9 เมตร ยังติดใน 90 วินาทีและไม่เรียก ToF ทั้งสองเที่ยว จุดเริ่ม 0 ไปได้ 26.1 → 22.9 เมตร และชน 2 → 4 ครั้ง ตัวเลือกนี้ยังไม่ควรเปิดใช้เป็นค่าเริ่มต้น [ข้อมูลการทดลองเรื่องเวลา](margin-pose-sample.json)
