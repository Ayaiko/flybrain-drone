# Ultrasonic + MPU6050 แยกช่องกล่องโล่งกับกิ่งพาดได้ไหม

จำลองการสแกนจากจุดนิ่งโดยใช้เพียงระยะเสียงสะท้อนกับมุมสัมพัทธ์จากไจโร แหล่งเบิกคือ Ultrasonic module แถว 40 และ MPU6050 แถว 43 ใน [รายการอุปกรณ์](https://docs.google.com/spreadsheets/d/13HSeevJYONpX67BIGQKyPhMh5o2fYkC9UluT4NYy2NQ/view?gid=538557757#gid=538557757) ชีตไม่ระบุรุ่น Ultrasonic ผลนี้จึงเป็นการทดสอบความไวต่อสมมติฐาน ข้อมูลคุณสมบัติ IMU ดูได้จาก [TDK](https://product.tdk.com/en/search/sensor/mortion-inertial/imu/info?part_no=MPU-6050)

## ฉากและแบบจำลอง

หน้ากล่องอยู่ห่างจุดหมุน 1.40 ม. กล่องลึก 0.50 ม. ผนังหลังช่องห่างจุดหมุน 3.40 ม. กิ่งเป็นแท่งแนวนอนเส้นผ่านศูนย์กลาง 20 มม. พาดเต็มช่อง ห่างจุดหมุน 1.55 ม. ศูนย์กลางกิ่งกับเซนเซอร์สูง 0.80 ม. เท่ากัน ทดสอบช่อง 1.30, 2.20 และ 2.60 ม. พิกัดวัตถุมีเฉพาะตัวจำลองสัญญาณและตัววาดภาพ ตัวตัดสินได้รับเฉพาะพิสัยสะท้อนและมุมวัด

กวาด 360 องศาใน 12 วินาที เก็บ Ultrasonic 15 ครั้ง/วินาที (181 ตัวอย่างรวมต้นและท้าย) ประมาณพิสัยสะท้อนแรกในภาคตัดแนวราบด้วย 65 รังสี ทดสอบครึ่งมุมลำเสียง 5°, 8°, 12° ระยะจำลอง 0.03–4 ม. เพิ่ม noise ส่วนเบี่ยงเบนมาตรฐาน 12 มม. และโอกาสอ่านหาย 2.5% ต่อครั้ง ผนังและกล่องให้เสียงกลับเมื่ออยู่ในลำเสียง ส่วนกิ่งกำหนดโอกาสให้ echo ต่อ ping ที่มีแนวเห็นกิ่งและไม่มีวัตถุใกล้กว่าบังในรังสีนั้น 0%, 3%, 15%, 60% หรือ 100% เมื่อกิ่งไม่สะท้อนยังรับ echo จากวัตถุด้านหลังได้ กรณีไม่มี echo บันทึกเป็นข้อมูลขาด

จำลองแกน yaw ของ MPU6050 ที่ 120 Hz โดยอินทิเกรตอัตราหมุนที่มี bias คงที่ต่อรอบสุ่มใน ±0.4°/s และ white noise ส่วนเบี่ยงเบนมาตรฐาน 0.35°/s จุดเริ่มอ้างอิงกับแนวกึ่งกลางที่ทำเครื่องหมายไว้ สมมติฐานนี้ใช้สำหรับชุดที่วางนิ่งและตั้งระดับ การบินจริงมีการเอียง การสั่น การเลื่อนตำแหน่ง การสะท้อนหลายทางและเสียงรบกวนที่ยังไม่ได้จำลอง โอกาสได้ echo ในที่นี้เป็นอิสระระหว่าง ping; ในการวัดจริงการพลาดหลายครั้งอาจสัมพันธ์กันจากท่าหรือวัสดุของกิ่ง

## เกณฑ์ตัดสิน

ทดสอบคำถามว่า “อนุญาตให้ตรงผ่านแนวกลางได้ไหม” ใช้ฟังก์ชัน corridor_depth เดิม ตรวจหน้าตัดกว้างอย่างน้อย 0.90 ม. ตามระยะ 0.8, 1.4, 2.0 และ 2.6 ม. มุมแบ่งช่องละ 10° ใช้ค่าระยะต่ำสุดที่วัดได้ในแต่ละช่อง และต้องผ่านเกณฑ์ห้าช่องกลางของ planner เดิม (ระยะเกิน 1.4 ม.) ด้วย PASS หมายถึงมีข้อมูลรองรับถึง 2.6 ม. HOLD หมายถึงวัดพบระยะสั้นในทิศที่ต้องใช้ UNKNOWN หมายถึงข้อมูลไม่พอ กรณีหลังไม่อนุญาตให้ผ่าน ทั้งวงจรเลือกทิศอ้อมและพลวัตการบินอยู่นอกการทดสอบนี้

## ผล

10,800 สแกน จาก 3 ความกว้าง × 3 มุมลำเสียง × 6 สภาพ echo (รวมช่องโล่ง) × 200 seeds สภาพโล่งกับมีกิ่งของแต่ละคู่ใช้ความคลาดไจโร range noise และชุด ping ที่อ่านหายเหมือนกัน

| ครึ่งมุมลำเสียง 8° | โล่ง อนุญาตผ่าน / 200 | มีกิ่ง อนุญาตผิด / 200 เมื่อโอกาสได้ echo ต่อ ping เป็น 0%, 3%, 15%, 60%, 100% |
|---|---:|---|
| 1.30 ม. | 0 | 0, 0, 0, 0, 0 |
| 2.20 ม. | 0 | 0, 0, 0, 0, 0 |
| 2.60 ม. | 200 | 200, 102, 3, 0, 0 |

ช่อง 1.30 ม. ถูกหยุดตั้งแต่ขอบกล่องเพราะ echo ไม่ได้บอกตำแหน่งด้านข้างภายในลำเสียง และ planner เก็บระยะต่ำสุดในช่องมุม ผล HOLD เหมือนกันทั้งสองฉากจึงใช้ยืนยันการตรวจพบกิ่งไม่ได้ ในช่องกว้าง 2.60 ม. เมื่อกิ่งสะท้อนอ่อน planner อาจเห็นผนังด้านหลังแล้วอนุญาตผิด แม้มุมหมุนจะถูกประมาณได้ดี
