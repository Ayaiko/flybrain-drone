# เลือกช่องทางต่อเนื่องด้วย ToF ใน fastsim

วงจรนำทางใช้ระยะ ToF หน้าและทิศจากการหมุนสแกน ไม่ได้อ่านวัตถุหรือจุดชนจากแผนที่สนามเพื่อให้คะแนนช่อง ตำแหน่งที่ซิมประมาณให้ใช้ตามระบบเดิมในการตามเป้าหมายและวัดระยะระหว่างจุดสแกน รูปทรงโลกใช้ประเมินการชนและวาดรีเพลย์

แบ่งรอบลำเป็น 36 ช่องทิศ เก็บค่าระยะต่ำสุดที่วัดได้ในแต่ละช่องและรับข้อมูลอายุน้อยกว่า 15 วินาที สำหรับทิศที่ผ่านเกณฑ์เดิม ตรวจว่ารังสีที่มีตัวอย่างทั้งซ้ายและขวารองรับหน้าตัดกว้าง 0.90 ม. ที่ระยะ 0.8, 1.4, 2.0, 2.6 และ 3.2 ม. ตามลำดับ หยุดนับความลึกเมื่อหน้าตัดแรกไม่ผ่าน วิธีนี้ประมาณจากลำแสงที่วัดได้ จึงยังมีจุดบอดระหว่างตัวอย่างและหลังสิ่งบัง

| config | ความแตกต่างจาก depart-loom35 |
|---|---|
| corridor-depth | ให้คะแนนช่องลึกต่อเนื่องเพิ่ม 0.7 ต่อเมตร |
| corridor-preview | เหมือน depth และเริ่มสแกนเมื่อ ToF ต่ำกว่า 2.2 ม. ตั้งต้นครั้งถัดไปเมื่อย้ายอย่างน้อย 1.2 ม. ส่วนการเบรกฉุกเฉินยังทำงานได้ทุกเฟรม |
| corridor-forward | นับประโยชน์ของความลึกเฉพาะองค์ประกอบไปทางเป้าหมาย เริ่มสแกนล่วงหน้าที่ 1.6 ม. |
| corridor-follow | เหมือน forward แต่จำทิศที่ลองแล้วและเดินทางช่วงละ 0.8–1.6 ม. ตามความลึกที่วัดได้ โดยตรวจ ToF ระหว่างเคลื่อน |
| corridor-approach | เหมือน follow และเริ่มสแกนที่ 2.2 ม. |

## สนามเป้าหมาย

hard 0 จุดเริ่ม 1, pose 50 Hz, pilot 30 Hz, ความสูงเป้าหมาย 1.5 ม., เวลาสูงสุด 600 วินาที ทั้งหมดใช้เกณฑ์หยุดเดิม ทดสอบทั้งเปิดตั้งแต่ออกตัวและให้บินเหมือนกันจนข้าม y=38 ม. แล้วจึงเปิดตัวเลือกใหม่ (ก่อนเขตกิ่งที่ y=40 ม.) ตำแหน่งและมุมที่บันทึกเหมือนกัน ค่า ToF ต่างกันสูงสุดต่ำกว่า 2×10⁻¹² ม. ถึงเฟรมสลับที่ 256.47 วินาที เงื่อนไข 38 ม. มีเฉพาะชุดทดลองควบคุม

| รุ่น | เปิดตั้งแต่ออกตัว ม. / ชน | เริ่มจากทางเข้าเดียวกัน ม. / ชน |
|---|---:|---:|
| depart-loom35 | 44.377 / 1 | 44.377 / 1 |
| corridor-depth | 42.086 / 0 | 42.188 / 1 |
| corridor-preview | 11.686 / 2 | 42.116 / 1 |
| corridor-forward | 47.460 / 0 | 44.216 / 1 |
| corridor-follow | 46.370 / 0 | 47.592 / 1 |
| corridor-approach | 42.522 / 1 | 42.467 / 1 |

ช่องที่ให้คะแนนด้วยความลึกอย่างเดียวทำให้เลือกกลับด้านหลัง ระหว่างที่ติดแถว y=42 รุ่น depth เลือกทิศประมาณ 220–280 องศาหลายครั้งเพราะระยะที่รองรับถึง 3.2 ม. (แกน y บวกอยู่ที่ 90 องศา) การให้คะแนนความลึกที่พาเข้าใกล้เป้าหมายช่วยให้เที่ยวจากจุดเริ่มจริงข้ามเส้น 47 ม. รุ่น forward ไปได้ 47.460 ม. ชน 0 ครั้ง แต่ยังสั้นกว่าจุดไกลสุดของ depart-direct ในรอบก่อนที่ 47.676 ม. การเปิดสแกนที่ 2.2 ม. ในเที่ยวเปรียบเทียบทางเข้าเดียวกันเริ่มเห็นสิ่งกีดขวางที่ y=38.6 ม. และส่งคำสั่งสแกนก่อนเข้าเขตกิ่ง แต่ไปไม่ถึง 47 ม. ทั้งหกรุ่นในสนามเป้าหมายไปไม่ถึงเกณฑ์ 52 ม.
